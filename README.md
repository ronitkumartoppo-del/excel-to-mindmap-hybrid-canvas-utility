# Excel-to-MindMap Hybrid Canvas Utility

GitHub is the source of truth for this project.

One workspace. One data model. Table and canvas show the same nodes.

## Run (for a developer or hosted build)

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:3000).

No API key is required for map, table, import, or export.

## What is included

- Shared node model for Table and Mind Map
- CSV / XLSX import with column mapping
- CSV / XLSX / JSON export
- Undo / redo
- Freeform + tree layouts
- Node drag on the canvas

## What is not committed

- node_modules
- dist / build output
- .env secrets
